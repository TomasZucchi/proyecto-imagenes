# proyecto-imagenes

Integrantes: Mauro Fernandez, Tomás Caceres, Tomás Zucchi

Este proyecto es una aplicación de procesamiento de imágenes en Python. Permite editar, mejorar y preparar fotos para redes sociales, además de generar bocetos estilo dibujo.

## Estructura del proyecto

fotoapp.py: Módulo principal con todas las funciones y un menú interactivo.

fotoapp_testdev.ipynb: Notebook para probar las funciones y visualizar resultados directamente.

imagenes: Carpeta con imágenes de prueba.
